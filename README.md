## 📱 Descripción

MindTrack es una aplicación móvil desarrollada en **Kotlin** y **Jetpack Compose** que te ayuda a descubrir tu perfil de toma de decisiones a través de una simulación interactiva de 3 minutos. Mediante escenarios realistas, evalúa tus patrones de pensamiento y comportamiento en situaciones de decisión.

## ✨ Características

- **Simulación Rápida**: Completa el perfil en solo 3 minutos
- **3 Escenarios**: Evaluación basada en situaciones realistas
- **3 Perfiles**: Resultados personalizados según tus elecciones
- **Interfaz Moderna**: Diseño intuitivo con animaciones fluidas
- **Modo Oscuro**: Soporte para tema claro y oscuro
- **Historial**: Revisa tus sesiones anteriores

## 🚀 Instalación

### Prerrequisitos
- Android Studio Arctic Fox o superior
- JDK 11 o superior
- Dispositivo Android con API 21+ o emulador

### Pasos
1. Clona el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/MindTrackApp.git
   ```
2. Abre el proyecto en Android Studio
3. Sincroniza Gradle
4. Ejecuta en dispositivo o emulador

## 📖 Uso

1. **Inicio**: Presiona "Iniciar Simulación" en la pantalla principal
2. **Escenarios**: Lee cada situación y selecciona la opción que mejor represente tu pensamiento
3. **Resultado**: Recibe tu perfil de toma de decisiones
4. **Historial**: Revisa sesiones previas en la pestaña de historial

## 🛠️ Arquitectura

- **MVVM**: Patrón de arquitectura con ViewModel
- **Jetpack Compose**: UI declarativa moderna
- **Navigation Component**: Manejo de navegación
- **StateFlow**: Gestión de estado reactiva
