## 📱 Descripción

MindTrack es una aplicación móvil de vanguardia desarrollada en **Kotlin** y **Jetpack Compose** diseñada para analizar y descubrir tu perfil de toma de decisiones. A través de simulaciones interactivas basadas en escenarios del mundo real, la app evalúa patrones cognitivos y conductuales para entregarte un diagnóstico preciso sobre tu estilo de pensamiento.

## ✨ Características Principales

- **Simulación Dinámica**: Evaluación completa en menos de 3 minutos.
- **Escenarios Realistas**: Decisiones basadas en contextos laborales, sociales y personales.
- **Perfiles Especializados**: Clasificación entre Pensador Racional, Estratégico o Impulsivo.
- **Deep Dark UI**: Interfaz moderna, minimalista y profesional con tema oscuro profundo.
- **Dashboard de Estadísticas**: Seguimiento de rachas, sesiones completadas y progreso.
- **Sistema de Logros**: Desbloquea hitos a medida que exploras diferentes rutas de decisión.

## 🛠️ Integración con API RESTful

La aplicación está totalmente sincronizada con una infraestructura backend (Spring Boot + PostgreSQL) para garantizar la persistencia y seguridad de los datos:

- **Autenticación**: Registro e inicio de sesión integrados con validación en el servidor.
- **Gestión de Perfil**: Actualización de biografía y fotos de perfil con persistencia remota.
- **Historial Cloud**: Sincronización automática de todas las sesiones de simulación.
- **Estadísticas y Logros**: Almacenamiento remoto de métricas de usuario, rachas y logros desbloqueados.
- **Manejo de Red**: Implementación robusta con Retrofit y manejo de estados offline/error.

## 🚀 Tecnologías y Arquitectura

- **Arquitectura MVVM**: Separación estricta de responsabilidades para un código mantenible.
- **Repository Pattern**: Capa de abstracción para el manejo de fuentes de datos (Remota/Local).
- **Jetpack Compose + Material 3**: UI declarativa con componentes de última generación.
- **StateFlow & Coroutines**: Gestión de estado reactiva y operaciones asíncronas eficientes.
- **Retrofit & OkHttp**: Consumo de API RESTful con interceptores de logging.

## ⚙️ Instalación

1. **Clonar el repositorio**:
   ```bash
   git clone https://github.com/tu-usuario/MindTrackApp.git
   ```
2. **Abrir en Android Studio**: Importar el proyecto y sincronizar archivos de Gradle.
3. **Requisitos**: JDK 11+, Android API 26+ (Android 8.0).
4. **Ejecución**: Instalar en un dispositivo físico o emulador.
